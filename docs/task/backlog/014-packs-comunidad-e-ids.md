# T-014 · Packs de comunidad e IDs con prefijo

- **Estado:** backlog
- **Prioridad:** media (alta si se abre a la comunidad)

## Objetivo
Que miles de archivos de distintas personas puedan convivir sin pisarse.

## Alcance
- Formato `pfm-pack`: `{ id, autor, versión, descripción, depende_de, contenido }`.
- IDs con prefijo (`autor/equipo`) y resolución de conflictos al importar.
- Lista de packs instalados, con opción de activar o desactivar cada uno.
