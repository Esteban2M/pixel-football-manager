# T-021 · Publicar en la web

- **Estado:** backlog
- **Prioridad:** baja (después de validar que el juego es divertido)

## Objetivo
Una versión pública gratuita para conseguir jugadores y comentarios.

## Alcance
- Hosting estático (GitHub Pages, Netlify o Vercel). No hace falta servidor, porque todo es local.
- Página de inicio simple y un canal de comentarios (Discord o GitHub Discussions).
