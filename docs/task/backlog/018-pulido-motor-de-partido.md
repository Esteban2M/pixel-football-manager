# T-018 · Pulido del motor de partido

- **Estado:** backlog
- **Prioridad:** alta (según el resultado de T-007)

## Objetivo
Que ver un partido sea emocionante: ritmo, jugadas claras, goles variados y momentos de tensión.

## Ideas
- Repetición de goles.
- Velocidad de simulación ajustable y "modo resumen" (solo jugadas clave).
- Indicaciones tácticas rápidas durante el partido (atacar o defender el resultado).
