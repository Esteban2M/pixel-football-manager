# T-011 · Narrativa: noticias, prensa y momentos

- **Estado:** backlog
- **Prioridad:** media

## Objetivo
Crear historias que se recuerden: clásicos, rachas, récords, el juvenil que debuta y marca, el veterano que se despide.

## Alcance
- Titulares generados a partir de eventos.
- Rivalidades (Clásico Joven, Clásico Nacional).
- Ruedas de prensa simples con 2 o 3 opciones que afectan la moral.
