# T-015 · JSON Schema público y versionado del formato

- **Estado:** backlog
- **Prioridad:** media

## Objetivo
Que la comunidad pueda crear contenido con autocompletado y validación en su editor (VS Code), y que los archivos viejos sigan funcionando.

## Alcance
- `schemas/*.schema.json` para cada tipo de documento.
- Campo `schemaVersion` con migraciones automáticas.
- Guía "Crea tu primera liga" en docs.
