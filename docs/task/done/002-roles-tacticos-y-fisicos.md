# T-002 · Roles tácticos, físicos reales y más color

- **Estado:** hecho
- **Prioridad:** alta
- **Creada:** 2026-10-14 · **Terminada:** 2026-10-14
- **Commit(s):** 1a3ac38

## Objetivo
Cada jugador tiene una posición y un rol táctico, como en el fútbol real, y el partido se ve más vivo.

## Alcance
- 24 roles tácticos (p. ej. portero líbero, central con salida, mezzala, enganche) que cambian el comportamiento en el motor.
- Alineación automática según el rol, con búsqueda local.
- Estatura, complexión y apariencia reales para CAZ y AME.
- Estadio con público animado, vallas publicitarias y una paleta más saturada.

## Criterios de aceptación
- [x] El rol modifica las decisiones en el partido.
- [x] El editor muestra la idoneidad por rol.
