# T-001 · Prototipo jugable (v0.1)

- **Estado:** hecho

- **Creada:** 2026-10-14 · **Terminada:** 2026-10-14

## Objetivo
Tener una primera versión jugable en el navegador para probar mecánicas: un juego tipo Football Manager con un creador de pixel art.

## Alcance
- React + Vite, todo local (localStorage), sin servidor.
- Cruz Azul y América con plantillas reales del Apertura 2026.
- Motor de partido 2D en tiempo real: 22 agentes, física del balón, IA por utilidad, tarjetas, cansancio, cambios.
- Tácticas: 5 formaciones, mentalidad, presión, ritmo y amplitud.
- Pixel Art Studio: editor libre, galería, escudos y retratos.
- Editor de equipos y jugadores.

## Criterios de aceptación
- [x] Jugar un partido completo con control táctico.
- [x] Crear un equipo propio con kits y escudo.
- [x] Pruebas automáticas del motor.
